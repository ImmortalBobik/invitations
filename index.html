Добавить гостей

Строка с двоеточием на конце («Немцы:») начинает новую группу. В Word-файле группы берутся из заголовков между нумерованными списками.

Шаблон

Растяните рамку там, где должно стоять имя. Можно нарисовать новую рамку мышкой.

имя

Текст приглашения

Новая строка в поле — новая строка на приглашении.

Обращение

{имя} заменится именем гостя. Какой вариант брать, решает отметка «он / она / пара» в списке гостей.

Старое имя на картинке

В рамке уже что-то нарисовано — наверное, имя из образца. Включите «Закрасить», иначе новое имя ляжет поверх.

Длинные имена

Если имя не влезает или задевает рисунок, программа сама уменьшит его, сдвинет в сторону или перенесёт на две строки — в этих пределах:

Проверить на имени

Например, «Дорогая тётя Галя» вместо «Дорогая Тётя Галя». Остальные приглашения не изменятся.
